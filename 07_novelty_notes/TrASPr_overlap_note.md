# 查重记录 1：TrASPr（eLife 2025, "Generative modeling for RNA splicing prediction and design"）

读取日期 2026-11-04（eLife 全文前 100k 字符；Data availability 段未读到，代码公开性待确认）。

## TrASPr 怎么处理 RBP 敲低

- 用到的 ENCODE 敲低只有 **3 个 RBP：TIA1、PTBP1、QKI**，加上 RBFOX 的 9 个验证靶点，合计 **68 个盒式外显子**。
- **没有"未见 RBP"设定。** 它的未见条件是组织/细胞系；敲低评测是序列层面的——把该 RBP 的结合基序突变掉，看模型预测的 ΔPSI 方向。
- 条件输入是组织 token 或 GTEx 中 3,344 个 RBP 表达量的 PCA 前 50 主成分；**eCLIP 没有作为输入**，只在讨论里提到是噪声较大的结合标签。
- 指标：方向一致（正确 / 无变化 / 相反）；dPSI 相关 0.34；正确率 "over 50%"，约 20% 方向相反；SpliceAI/Pangolin 各 10.3% 正确。
- 作者自述局限：敲低效应可能是间接的；基序是粗糙的结合表示。

## 与本项目的边界

| 维度 | TrASPr | 本项目 |
|---|---|---|
| 预测单位 | 序列 + 条件 → PSI | (被扰动 RBP, 事件) → ΔPSI |
| 敲低数据规模 | 3 RBP / 68 外显子 | 501 RBP / 983 实验 / 19 万事件 |
| 未见 RBP | 无 | 核心任务，三层特征协议 |
| 结合谱 | 未用 | 事件级 eCLIP 作为扰动编码器输入（H1） |
| 测量上限 | 无 | 同 RBP 双技术 + 重复拆分一致性 |
| 反向应用 | 无 | 癌前队列反向映射 |

结论：无直接重叠。可以在相关工作里把 TrASPr 作为"序列条件模型 + 基序突变模拟敲低"的代表，并把它的 68 外显子集合作为一个小型外部检查（对这 68 个外显子，我们的模型在 TIA1/PTBP1/QKI 上的方向准确率 vs 它报告的 >50%）。
